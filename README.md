# ANDRIL

Andril is a full-stack mobile and web application developed by Code Monkeys.

## Core Modules

1. Learning — Classrooms
2. Hobbies — Clubs
3. Dating — Rooms

## Technology Stack

- Mobile: Flutter + Dart
- Admin: Angular + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL + pgvector

## Project Structure

- andril-mobile/ — Mobile application
- andril-admin/ — Administration application
- andril-backend/ — Backend API
- infrastructure/ — Deployment configuration
- docs/ — Project documentation
- .github/ — GitHub collaboration configuration
